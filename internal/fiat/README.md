The code in this directory is autogenerated by the fiat-crypto project from a
formally verified model, following the same checked-in-generation pattern used
by Go's crypto/internal/fips140/nistec/fiat package.

The generated files were produced with:

    go generate

or, equivalently from this directory:

    go run generate.go

The generator runs fiat_crypto from:

    ghcr.io/islishude/fiat-crypto-go-tool@sha256:fa7d326be7c8ce419573e4f3165a88a41dfb0d29276887dd3c9de643f2723424

The shared pin is maintained in `../gentool/tool.go`. It selects a manifest
containing Linux ARM64 and AMD64 images. Regeneration with this digest reproduced
the checked-in arithmetic unchanged during the 2026-09-08 review fixes.

Set FIAT_CRYPTO_GO_TOOL_IMAGE only to deliberately override the audited pin,
for example with an immutable mirror digest. Set
FIAT_CRYPTO_BIN only when intentionally bypassing Docker with a local
fiat_crypto binary.
